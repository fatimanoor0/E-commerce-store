🛍️ Shopora – E-Commerce Store

A responsive e-commerce website built with React.js.

✨ Features

- 🏠 Home page with products
- 🔍 Product details
- 🛒 Add to cart & quantity controls
- 💳 Checkout page
- 🔔 Toast notifications
- 📱 Responsive design
- 💾 Cart data saved using LocalStorage

🛠️ Technologies

- React.js
- React Router
- JavaScript
- CSS
- Vite
- LocalStorage

🚀 Run Locally

npm install
npm run dev

Then open the localhost link in your browser.
